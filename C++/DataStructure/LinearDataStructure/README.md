##시간 복잡도

벡터 (동적 배열)
- 삽입 / 삭제
  - 시작 - 데이터를 한 칸씩 전부 이동시켜야됨.  1 * N = N
  - 중간 - 중간부터 데이터 이동.            1 / 2 * N = N
  - 끝 - 뒤에 새로운 데이터 저장.            1
- 임의 접근 - 메모리에 연속된 블록            1

리스트 
- 삽입 / 삭제
  - 시작 - 노드 연결  1
  - 중간 - 노드 연결  1     
  - 끝 - 노드 연결   1
- 임의 접근 - 순차 탐색으로 i번째 노드에 접근하려면 i번 이동. N
