# 🌳 Tree & Graph in C++

이 디렉토리는 C++로 구현한 트리(Tree)와 그래프(Graph) 자료구조 및 알고리즘 예제를 포함하고 있습니다. 각 폴더는 특정 개념과 알고리즘을 중심으로 구성되어 있으며, 학습 목적에 맞춰 단계적으로 탐색할 수 있습니다.

## 📚 학습 순서 및 개념 요약

### 1️⃣ Tree
- **설명**: 트리는 계층적 구조를 표현하는 비선형 자료구조입니다. 이진 트리(Binary Tree)와 이진 탐색 트리(Binary Search Tree, BST)를 중심으로 구현됩니다.
- **학습 포인트**:
  - 노드 구조체 정의
  - 삽입/탐색/삭제 기능
  - 전위, 중위, 후위 순회 알고리즘

### 2️⃣ RecursiveFunction
- **설명**: 재귀 함수는 자기 자신을 호출하여 문제를 해결하는 방식입니다. 트리 순회나 DFS 알고리즘 등에 필수적으로 사용됩니다.
- **학습 포인트**:
  - 함수 호출 스택 이해
  - 재귀 종료 조건 설정
  - 트리 탐색 및 문제 해결

### 3️⃣ Graph
- **설명**: 그래프는 정점(Vertex)과 간선(Edge)으로 구성된 자료구조로, 다양한 관계를 모델링할 수 있습니다.
- **학습 포인트**:
  - 인접 리스트와 인접 행렬 구현
  - 방향 그래프, 무방향 그래프 생성
  - 그래프 출력 및 관리 기능

### 4️⃣ DFS
- **설명**: 깊이 우선 탐색(DFS)은 가능한 한 깊게 탐색하다가 더 이상 갈 곳이 없으면 되돌아가는 방식입니다.
- **학습 포인트**:
  - 재귀 또는 스택 기반 구현
  - 방문 노드 체크
  - 백트래킹 기법의 기초

### 5️⃣ BFS
- **설명**: 너비 우선 탐색(BFS)은 가까운 노드부터 차례로 탐색하는 방식으로, 최단 거리 문제에 효과적입니다.
- **학습 포인트**:
  - 큐(Queue)를 활용한 구현
  - 거리 기록 및 레벨 탐색
  - 탐색 순서 관리

### 6️⃣ PriorityQueue
- **설명**: 우선순위 큐는 각 요소에 우선순위를 부여하여 높은 우선순위를 가진 요소가 먼저 처리되도록 합니다. 힙(Heap) 자료구조로 구현됩니다.
- **학습 포인트**:
  - 최소/최대 힙 구현
  - STL priority_queue 활용법
  - 다익스트라 알고리즘 준비
